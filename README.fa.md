# 🎛️ پنل مدیریت حرفه‌ای (Admin Dashboard)

یک داشبورد مدیریتی **چند صفحه‌ای، کاملاً ریسپانسیو و فارسی (RTL)** ساخته‌شده با
**HTML5، CSS3، JavaScript، jQuery و Bootstrap 5**.

---

## 🎯 اهداف پروژه
ارائه یک قالب داشبورد مدرن، تمیز و آماده برای استفاده در پنل‌های مدیریتی،
با تمرکز بر تجربه کاربری، واکنش‌گرایی (Responsive) و قابلیت توسعه.

---

## ✨ امکانات پیاده‌سازی‌شده

- ✅ **صفحه ورود (Login)** حرفه‌ای با بخش تصویری، نمایش/مخفی رمز و اعتبارسنجی
- ✅ **احراز هویت ساده سمت کلاینت** (localStorage) با محافظت از صفحات (Auth Guard)
- ✅ **سایدبار (Sidebar) ریسپانسیو** با قابلیت جمع‌شدن (Collapse) در دسکتاپ و کشویی در موبایل
- ✅ **نوار بالا (Topbar)** با جستجو، اعلان‌ها، منوی کاربری
- ✅ **حالت روشن / تاریک (Dark Mode)** با ذخیره در localStorage
- ✅ **صفحه داشبورد** شامل کارت‌های آماری، نمودار خطی، نمودار دایره‌ای، جدول سفارش‌ها و فید فعالیت
- ✅ **مدیریت کاربران (CRUD کامل)** با استفاده از **RESTful Table API** (افزودن/ویرایش/حذف/جستجو/فیلتر)
- ✅ **صفحه تحلیل و آمار** با ۴ نوع نمودار (میله‌ای، دایره‌ای، افقی، رادار)
- ✅ **صفحه محصولات** به‌صورت کارت‌های گرید
- ✅ **صفحه سفارش‌ها** با فیلتر تب‌دار
- ✅ **صفحه پروفایل** قابل ویرایش
- ✅ **صفحه تنظیمات** با تب‌های عمومی، اعلان، امنیت و ظاهر
- ✅ سازگار با موبایل، تبلت و دسکتاپ

---

## 🗂️ ساختار فایل‌ها

```
index.html          → صفحه ورود (Login)
dashboard.html      → داشبورد اصلی
analytics.html      → تحلیل و آمار
users.html          → مدیریت کاربران (CRUD)
products.html       → محصولات
orders.html         → سفارش‌ها
profile.html        → پروفایل کاربر
settings.html       → تنظیمات
css/
  └── style.css     → استایل اصلی + تم تاریک + ریسپانسیو
js/
  ├── main.js       → منطق مشترک (تم، سایدبار، احراز هویت)
  ├── layout.js     → رندر سایدبار و topbar مشترک
  ├── dashboard.js  → نمودارها و جداول داشبورد
  ├── analytics.js  → نمودارهای صفحه تحلیل
  └── users.js      → عملیات CRUD کاربران
```

---

## 🔗 مسیرهای ورودی (URIها)

| صفحه | مسیر | توضیح |
|------|------|-------|
| ورود | `index.html` | نقطه شروع — پس از ورود به `dashboard.html` می‌رود |
| داشبورد | `dashboard.html` | نمای کلی آمار و نمودارها |
| تحلیل | `analytics.html` | نمودارهای تحلیلی |
| کاربران | `users.html` | مدیریت کاربران (CRUD) |
| محصولات | `products.html` | لیست محصولات |
| سفارش‌ها | `orders.html` | لیست سفارش‌ها با فیلتر |
| پروفایل | `profile.html` | اطلاعات کاربر |
| تنظیمات | `settings.html` | تنظیمات پنل |

> **نکته دمو:** در صفحه ورود هر ایمیل و رمز عبوری پذیرفته می‌شود.

## 🗄️ مدل داده (RESTful Table API)

### جدول `users`
| فیلد | نوع | توضیح |
|------|-----|-------|
| `id` | text | شناسه یکتا (خودکار) |
| `name` | text | نام کامل |
| `email` | text | ایمیل |
| `role` | text | نقش (مدیر / ویرایشگر / کاربر) |
| `status` | text | وضعیت (active / pending / inactive) |
| `phone` | text | شماره تلفن |
| `avatar` | number | شماره آواتار (pravatar) |

**عملیات API استفاده‌شده در `users.html`:**
- `GET    tables/users?limit=100` — دریافت لیست
- `POST   tables/users` — افزودن کاربر
- `PATCH  tables/users/{id}` — ویرایش
- `DELETE tables/users/{id}` — حذف
